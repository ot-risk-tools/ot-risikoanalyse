Privacy

In short: your analyses stay on your device. For the vulnerability search your browser queries three public data sources.

  • Local storage only. Projects, components, ratings and notes are kept in your browser's storage (localStorage), unencrypted. With the start file on Windows they are additionally saved as a file on your PC. There is no server run by the operator, no user account and no transmission of your analyses.
  • Queries to third parties. When you search for vulnerabilities or update threat data, your browser fetches data directly from the following services. Your IP address and the search term are transmitted (product name, vendor, version or CVE number), but not the project name, machine, customer or rating:
    • National Vulnerability Database, NIST, USA (services.nvd.nist.gov)
    • FIRST.org, USA, for EPSS scores (api.first.org)
    • GitHub, USA, for the CISA catalogue of known exploited vulnerabilities (raw.githubusercontent.com)
    Without these functions no query is made.
  • Hosting. The online edition is delivered through GitHub Pages (GitHub, Inc., USA). Like any web server, GitHub processes technical data when the page is requested, such as IP address, time and browser details. The operator of this page has no influence on that and no access to it. See GitHub's privacy statement.
  • Offline storage. So that the app starts without internet, the browser stores the program files locally (service worker). They contain no personal data.
  • No cookies, no analytics, no advertising. The app loads no fonts or scripts from third parties.
  • Deleting. Use “⋯ → Delete all data on this device” or clear your browser data.

A list of unpatched vulnerabilities of a plant is confidential. For real company data use only devices approved for it, and pass reports and backup files only to authorised recipients.
