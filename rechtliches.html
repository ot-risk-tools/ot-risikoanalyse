Datenschutz

Kurz gesagt: Deine Analysen bleiben auf deinem Gerät. Für die Schwachstellensuche fragt dein Browser drei öffentliche Datenquellen ab.

  • Speicherung nur lokal. Projekte, Komponenten, Bewertungen und Notizen liegen im Speicher deines Browsers (localStorage), unverschlüsselt. Mit der Start-Datei unter Windows liegen sie zusätzlich als Datei auf deinem PC. Es gibt keinen Server des Betreibers, kein Benutzerkonto und keine Übertragung deiner Analysen.
  • Abfragen an Dritte. Wenn du Schwachstellen suchst oder Bedrohungsdaten aktualisierst, ruft dein Browser Daten direkt bei diesen Stellen ab. Dabei werden deine IP-Adresse und der Suchbegriff übertragen (Produktname, Hersteller, Version oder CVE-Nummer), nicht aber Projektname, Maschine, Kunde oder Bewertung:
    • National Vulnerability Database, NIST, USA (services.nvd.nist.gov)
    • FIRST.org, USA, für EPSS-Werte (api.first.org)
    • GitHub, USA, für die CISA-Liste aktiv ausgenutzter Schwachstellen (raw.githubusercontent.com)
    Ohne diese Funktionen findet keine Abfrage statt.
  • Hosting. Die Online-Fassung wird über GitHub Pages ausgeliefert (GitHub, Inc., USA). Wie jeder Webserver verarbeitet GitHub beim Abruf technische Daten wie IP-Adresse, Zeitpunkt und Browser-Angaben. Darauf hat der Betreiber dieser Seite keinen Einfluss und keinen Zugriff. Näheres: Datenschutzerklärung von GitHub.
  • Offline-Speicher. Damit die App ohne Internet startet, legt der Browser die Programmdateien lokal ab (Service Worker). Darin stehen keine persönlichen Daten.
  • Keine Cookies, keine Analyse, keine Werbung. Die App lädt keine Schriften oder Skripte von Dritten.
  • Löschen. Über „⋯ → Alle Daten auf diesem Gerät löschen“ oder durch Löschen der Browserdaten.

Eine Liste ungepatchter Schwachstellen einer Anlage ist vertraulich. Nutze für echte Firmendaten nur Geräte, die dafür freigegeben sind, und gib Berichte und Sicherungsdateien nur an berechtigte Empfänger weiter.
